## 陪伴助手（v2026.1113.1900）

- 🔍 分享給小智辨別（「＋」）：貼上轉傳內容，小智依「結論／理由／聖經怎麼說／怎麼溫柔回覆」回答。manifest 有 `share_target`（Android 安裝到主畫面後，可從其他 App 的分享選單直接送進來，網址 `?share=1&text=…`，會依記住的語言轉到對應頁）；iPhone 沒有這個功能，請用貼上。
- 👦 兒童模式（側欄）：自動改成「兒童・短」對象與長度、大字、問題卡片、回答自動朗讀、隱藏選單；系統提示限定適合兒童的內容；離開要家長答一題乘法，離開後恢復原本對象與長度。
- 😊 會動的小智：自繪 SVG（金色笑臉＋聖經），會眨眼；語音對談時聆聽會點頭、思考有泡泡、說話嘴巴會動；兒童模式首頁會跳動。
- 🎭 聖經人物對話（側欄或「＋」）：14 位人物或自行輸入；第一人稱、只根據聖經記載並附出處、標明是想像對話；不扮演耶穌、天父、聖靈；對話會記住人物，重開也延續。

## 教材助手（v2026.1113.1800）
- 📖 經文核對（xzplus.js）：回答裡「引號裡的經文＋出處」自動和 321互動聖經同一份經文比對（`/bible/toc.json` 與 `bible.<語言>.<分卷>.json`），出處後面顯示 ✓（相符）或 ⚠（字句略有不同／節數不對／對不上）；回答最後一行是核對摘要，點開可看小智引用和聖經原文的對照。
- ✨ 一鍵改寫（回答下方「⋯」）：更短、更詳細、更簡單、講給小孩聽、講給長輩聽、改成講台講稿、改成簡訊口吻、更正式；可還原原本的回答。
- 🎯 測驗與字卡（「⋯」）：從回答出 5 題選擇題（答對答錯即時說明、計分）和 6 張可翻面的字卡，可分享題目。
- 📷 拍照提問（輸入列「＋」）：拍照或選相片，縮成約 1400px JPEG，以 Anthropic 圖片格式（`content:[{type:'image',…},{type:'text',…}]`）送給 xiaozhi-proxy。若 proxy 只收文字，會顯示提示，需要更新 proxy。
- 📚 資料夾參考資料（資料夾設定）：加入 PDF（cdnjs pdf.js 3.11.174，第一次用時才下載）、Word .docx、文字檔或貼上文字；內容切段存在 IndexedDB（`fsrc_<資料夾>`），每次提問挑最相關的段落（總長 8,000 字內，少於 9,000 字就全放）連同出處放進系統提示。
